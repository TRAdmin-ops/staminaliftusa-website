# StaminaLift literature folders

Drop approved PDFs into the matching folder before publishing:

- `product-brochures/` - product and company brochures
- `operator-manuals/` - operator manuals and quick-reference guides
- `service-manuals/` - service and maintenance documentation
- `accessories/` - accessory specifications and compatibility sheets
- `case-studies/` - facility stories and implementation results
- `specifications/` - technical data sheets and dimensions

The 2026 RIHA Industries brochure is included in `product-brochures/`.
